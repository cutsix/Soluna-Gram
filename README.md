# Soluna-Gram

Soluna-Gram 是一个基于 [Kurigram](https://github.com/KurimuzonAkworworka/kurigram) 的 Telegram 开源项目，支持通过插件和内置模块扩展功能。

## 致谢

Soluna-Gram 的诞生离不开以下开源项目：

- **[PagerMaid-Pyro](https://github.com/TeamPGM/PagerMaid-Pyro)** — 本项目最初基于 PagerMaid-Pyro 开发，其架构设计、模块系统和 pyromod 会话机制为 Soluna-Gram 提供了坚实的基础。感谢 TeamPGM 团队的工作。
- **[Kurigram](https://github.com/KurimuzonAkworworka/kurigram)** — Soluna-Gram 的底层 Telegram MTProto 框架，作为 Pyrogram 的活跃维护分支，提供了持续的 Layer 更新和稳定性改进。
